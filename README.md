
# PIC18F4580 Embedded C Programming

A collection of Embedded C programs developed using the **PIC18F4580 microcontroller** as part of my hands-on embedded firmware training.

This repository documents my practical learning and experiments with microcontroller peripherals, hardware interfacing, communication protocols, timers and control applications.

## Hardware and Development Tools

- **Microcontroller:** PIC18F4580
- **Programming Language:** Embedded C
- **IDE:** MPLAB X IDE
- **Compiler:** MPLAB XC8
- **Simulation Software:** Proteus Design Suite

## Topics Covered

| Folder | Topics |
|---|---|
| 01_GPIO | LED interfacing, port control and switch operations |
| 02_Bit_Manipulation | Bit shifting and nibble operations |
| 03_ADC | Analog-to-Digital Conversion |
| 04_UART | UART/USART transmission and reception |
| 05_Timers_Interrupts | Timer peripherals and interrupts |
| 06_PWM | PWM generation and duty-cycle control |
| 07_LCD_Keypad | LCD and keypad interfacing |
| 08_Motor_Control | DC motor and robot movement experiments |
| 09_Applications | Password systems, water-level control and other applications |
| 10_Proteus_Simulations | Proteus simulation projects |

## Practical Work

The programs in this repository include:

- GPIO configuration and LED blinking
- Switch-controlled LED operations
- Bitwise shifting and nibble manipulation
- ADC programming
- UART transmitter and receiver programs
- Timer configuration and delay generation
- PWM duty-cycle experiments
- LCD and keypad interfacing
- DC motor control
- Password-based access control
- Automatic water-level controller

## Proteus Simulations

Proteus projects are included to demonstrate circuit-level simulation of selected microcontroller experiments.

The simulation projects were tested in Proteus on my system.
